# Cursos Vacacionales de UNEMI

Landing page funcional y responsiva desarrollada con **React** y **Bootstrap** para la inscripción a cursos vacacionales de la Universidad Estatal de Milagro.

## Tecnologías

- React (componentes funcionales y JSX)
- Vite
- Bootstrap 5
- JavaScript (estados con `useState`)

## Estructura de componentes

- `Navbar` — navegación responsiva
- `Hero` — sección principal de bienvenida
- `Servicios` — información y oferta de cursos
- `Formulario` — inscripción con validaciones
- `Footer` — contacto y enlaces

## Funcionalidades

- Landing page organizada en componentes funcionales
- Diseño responsivo con Bootstrap
- Formulario controlado con `useState`
- Validaciones en tiempo real (nombre, correo, teléfono, edad, curso, modalidad, contraseña, términos)
- Mensajes dinámicos de error y éxito

## Cómo ejecutarlo (local)

```bash
npm install
npm run dev
```

Abre la URL que muestre Vite (normalmente `http://localhost:5173`).
